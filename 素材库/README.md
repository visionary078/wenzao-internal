# 问造社内部素材库

课程、选题、宣传要从这里取。库里没有的说法，先入库再对外用。

数据库文件是 `wenzao.db`，用来检索。文件本身放在仓库根目录的文件夹里：课程（总体设计、方案、教案、讲义、课程素材）、运营、师资、学生信息、财务、公司信息、会议纪要、法务与合规、采购与物料、场地。

库里的条目现在有五类：理念、规则、作品、套件、边界。作品按难度 1～4 收录物联网项目，并写了零件、估价和能不能上架。

卡内基、费曼只作内部检索和课堂动作。对外不写官方课程、商标授权或认证。这条已经记在库里的「边界」中。

## 查

在 `素材库` 目录：

```text
python db.py list
python db.py list --kind 作品 --difficulty 2
python db.py list --shelf 可以
python db.py search 卡内基
python db.py show 坐姿提醒
```

## 补

把新材料写成一篇 md，放进 `inbox`。第一段用 `字段: 内容`，空一行后写正文。格式见 `inbox/_补一条.md`。文件名不要以 `_` 开头。

```text
python db.py import-inbox
```

入库后的原稿会移到 `inbox/已入库`。同名同类型会更新，不会把后来补的条目清掉。

也可以直接把材料发来，说明它是理念、作品、套件、规则还是边界。
