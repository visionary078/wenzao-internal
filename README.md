# 问造社内部资料

可检索的条目在 `素材库/wenzao.db`。文件按下面的文件夹放。对外文案先查库，再写。

## 课程

- `课程/总体设计`：整条课程从哪到哪
- `课程/方案`：营期、产品方案
- `课程/教案`：一次课怎么上
- `课程/讲义`：学生带走的册子
- `课程/课程素材`：选题、零件、可改编的原材料

## 运营

- `运营/文案`：可以发出去的宣传文字
- `运营/渠道与执行`：渠道打法和待办
- `运营/网站`：站点页面

## 其余

- `师资`：老师资料
- `学生信息`：名册和联系方式。真实内容不上传
- `财务`：报价、收支、票据。真实内容不上传
- `公司信息`：主体、商业计划和合作文件
- `会议纪要`
- `法务与合规`：协议、隐私、未成年人边界
- `采购与物料`：套件、零件和供应商
- `场地`
- `素材库`：上面这些文件夹的检索库
