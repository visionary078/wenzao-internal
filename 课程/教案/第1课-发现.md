# 问造社 · AI创新课 第1课「发现」（120分钟）

适用：L1 二年级零基础（主线）｜L2 三、四年级/有Scratch基础（挑战线）
本课成果：每组提出1个「真实需求」，并用灵光做出1个能自己玩的小软件原型；每人完成Scratch第1个程序。
对齐课程体系：入门阶段第1次，为后续「找真用户、算成本、做产品」打地基。

## 一、学习目标
| 维度 | L1（二年级） | L2（挑战线） |
|---|---|---|
| 知识 | 知道「发明=发现麻烦+想办法」 | 能用「谁/在哪/遇到什么麻烦」三问写需求 |
| AI | 知道AI能听懂我说的话、帮我做东西；知道AI会出错 | 能把需求写成清楚的提示词并改进一次 |
| 编程基础 | Scratch：认识角色、舞台、绿旗、「移动」「说」积木（顺序） | 加上「重复执行」循环 |
| 商业意识 | 东西要做给「某个人」用 | 说出用户是谁、为什么他会想要 |

## 二、课堂流程（120分钟）
| 时间 | 环节 | 内容 |
|---|---|---|
| 0–10′ | 开场·组队 | 抽签分4组，起队名，讲积分规则 |
| 10–25′ | 哇！创新案例 | 3个真实发明，抢答「他发现了什么麻烦」 |
| 25–45′ | 需求侦探 | 麻烦大搜查+三问卡，组内投票选1个，组间PK |
| 45–70′ | AI小魔法 | 灵光把需求做成小软件；L2改一次提示词并对比 |
| 70–80′ | 休息 | |
| 80–105′ | Scratch基础 | L1顺序；L2加重复执行 |
| 105–115′ | 小组路演赛 | 每组2分钟，举牌投票 |
| 115–120′ | 总结 | 公布积分，发讲义和反馈表 |

积分兑换：10分=贴纸，30分=小奖品，100分=3D打印作品/盲盒；积分按个人+小组双账记，跨课累积。

## 三、分级说明（同一主题，两个出口）
- L1：口头说需求给AI，老师/助教帮打字；Scratch只做顺序。
- L2：自己写提示词；Scratch做循环；路演多说一句「谁会愿意用/买」。
- 以后高年级（L3）：本课可加「采访1位真用户」和「估算做这个要花多少钱」。

## 四、物料
电脑（预装灵光、Scratch）、三问卡、场景卡（家/学校/路上）、便利贴、积分贴纸、投票牌、A5讲义、反馈表、奖品。

## 五、讲义（A5宣传册，4面）
**封面**：问造社·第1课「发现」— 每个发明家，都从发现一个麻烦开始！
**第2面·今天看到的发明**：3个案例小图+一句话。「我最喜欢___，因为___。」
**第3面·我的需求侦探卡**：谁？___ 在哪？___ 遇到什么麻烦？___ 我想用AI做一个___ 来帮他。
**第4面·我学会的编程**：Scratch积木图（绿旗、移动、说、重复执行）；回家挑战：让小猫走一圈说出你的名字。底部：积分记录格+下节课预告「第2课：想办法」。
