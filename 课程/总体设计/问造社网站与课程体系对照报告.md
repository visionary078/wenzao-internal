# 问造社网站与课程体系对照报告

对照对象：

- 线上站：[问造社](http://wenzao.leeeeeo.xyz/)
- 方案：《少儿 AI × 编程与单片机硬件完整课程体系方案》（最新版，4 页）

本报告只做对照和建议。网站页面未改。

## 结论

网站现在卖的是一套面向小学高年级和初高中的探究式 STEM 课：观察、做原型、讲清楚。新方案卖的是另一条线：从二年级零基础开始，每一级都要交出一件有人愿意用、算得清成本、能被检验的产品；编程是把这件产品做出来的手段。

小班人数建议统一写成 **4–8 人**。网站现在写的是 **2–6 人**（「小班导师共同体」和「问造 Inquiry Studio 编程与 AI 主课」两处）。2 人撑不起零件超市、跳蚤市集和用户访谈；超过 8 人，主讲没法每 15 分钟蹲到每个孩子身边。

## 网站和方案对不上的地方

| 位置 | 网站现在 | 方案要求 |
|---|---|---|
| 招生年龄 | 小学高年级与初中、高中，不混龄 | 二年级零基础是主力；有基础的 15 分钟小测后可进 L2–L4 |
| 班额 | 2–6 人 | 改为 4–8 人 |
| 主课结构 | 90 分钟体验 + 15 节主课 + 90 天孵化 + 营地 | L0 一日营，之后 L1–L4 各 8 次、每次 90 分钟 |
| 主线 | 探究、工程、表达 | 商业结果在前：用户、成本、试用、认购；编程用来完成这些结果 |
| 入口产品 | 没有 39.9 元体验营，联系方式仍是「待补充」 | L0：39.9 元，10–20 人，上午机甲留场，下午声光装置和宣传册带走，15:30 家长看 60 秒演示 |
| 带走的东西 | 问题卡、访谈、原型、路演 | 每一级都有实物，外加成本单、用户原话、试用或认购证据 |
| AI | 素养：何时采纳、追问、停下 | 二年级按住麦克风做三步追问；L4 才把 Agent 接到自己的硬件上 |

网站上「从好奇出发，学会解决真实问题」「先探究再结论」「判断留在人手里」可以留。它们应该长在产品任务里面，不要单独再开一门口号课。

## L1–L4：商业结果是主线，编程是用来交货的

L0 仍是筛选入口，不算一级产品课。上午用场地里的掌心机甲看清「一个输入、一个动作」，机甲留在场内。下午只改 Scratch 里两个数字，调通一件防呆声光装置，定下这件东西给家里谁用，并用 100 以内加减法算出第一张零件单。15:30 向家长做 60 秒演示。带走装置、宣传册和成本小票。

### L1 入门：做出一件家里有人要用的小产品

适合二年级零基础，或体验营升上来的孩子。8 次，每次 90 分钟，4–8 人。

孩子要交出一件给妈妈、爸爸或同桌解决一个小麻烦的装置，并在第 8 课的班级跳蚤市集上用 60 秒讲清楚、让家长用认购币下单。

编程学的是 Scratch 的顺序、条件、循环、变量和函数，硬件用防插反模块，不碰面包板飞线，也不敲英文代码。AI 只用来语音追问自己不懂的一句。商业动作是：每节课拿 50 元预算币去零件超市买模块，自己算成本。

结业带走防呆互动盒、8 册宣传册和市集认购结果。

### L2 进阶：做出一件真实的人试用过的最小产品

适合学完 L1 的孩子，或小测证明已经会 Scratch 的孩子。

主线是走出教室，问 3 个真实的人，带回 3 句原话，在 50 元材料预算里做出能用的版本，交给用户带回家试用 3 天，再只改最关键的一处。

编程在这里才从积木过渡到 Arduino：调用超声波、温湿度、舵机，并让两块板用简单暗号互相收发。AI 用来查竞品差评和挑自己方案的刺。

结业带走这件硬件、用户签字和 90 秒路演。

### L3 高阶：把能用的原型收成一件可以交给别人的准商品

适合完成 L2，或已经会代码和硬件、经小测跳级的孩子。

主线是算清如果做多一件要花多少钱，交给 3–5 名种子用户内测，并写出说明书和定价。

编程用来甩掉一碰就松的飞线：自己画电路板、在板上印上产品名，用 3D 做出卡得住的外壳。切割和打印由老师操作。

结业带走电路板、外壳、成本与定价表、内测记录。

### L4 孵化：做出一件别人愿意认购的智能产品

适合完成 L3、软硬件和结构都能自己讲清的孩子。

主线是把一件普通感应器变成某个具体场景里值钱的产品，到创客市集上接受陌生人是否认购的检验。

编程是给自己的硬件写清五件事：它是谁、只做什么、看哪个传感器、调用哪个硬件动作、什么时候必须停下来问人，再把这套说明接到板上。

结业带走可展示的智能硬件、商业评估页和认购单。

## 四级共用的验收尺

四级共用同一张验收尺，只是证据变硬：

1. 给谁用。
2. 对方原话是什么。
3. 自己改了哪一处。
4. 用了哪一段程序和哪一个零件。
5. 成本多少。
6. 失败过一次之后，下一步只改哪里。

二年级用口头和填空。L2 以后必须指向真实的人和真实的试用。
